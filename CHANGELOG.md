# Changelog

## 0.2.1

Published to npm as `@methodox/dhole`, with the same build as 0.2.0: no change to the language, the drawings or the API. The package names its module, its types and its plain script (`@methodox/dhole/script`), and no longer points older bundlers' `browser` field at the plain script, which has no exports. `languageVersion` stays 0.2.0, the language's version, which this release does not change.

## 0.2.0

The first public build: Dhole 0.2.0, the language of Divooka's `Divooka.Visualization.Dhole` 0.2.0, drawn on a web page. Fifteen of its seventeen kinds are drawn - flowchart, sequence, state, class, entity, mindmap, timeline, gantt, pie, bar, line, xy, radar, quadrant and kanban - each held to Divooka's own drawing of the same text: the same problems in the same words, the same summary, and every word of the picture where Divooka puts it. Sankey diagrams and tables are read and said to be drawn in Divooka only, for now.
